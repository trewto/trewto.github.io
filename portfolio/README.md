# Publishable portfolio

This is the live, editable website source. Make all future website changes in this folder.

Copy the contents of publishable into your GitHub Pages repository root, including .nojekyll and the complete assets directory. No build or installation is required for this folder. For branch publishing, select main and /(root) in Settings > Pages.

Open the site through HTTP/HTTPS for embedded YouTube playback. Opening index.html directly from disk shows an on-page explanation and a local-preview link instead of redirecting to YouTube. Without JavaScript, video links open YouTube directly.

The supplied CV is unchanged. Search-engine exclusion is included, but is not access control; robots.txt applies only at the hostname root.

Private resources, development scripts, and audit files are outside this folder.
